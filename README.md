# HR-Data-Analysis-Python
HR Data Analysis using Python Analyzed 2M employee records to generate HR insights on attrition, salary trends, performance, and workforce distribution using Python (Pandas, NumPy, Matplotlib). Includes data cleaning, EDA, and business-focused visualizations in a Jupyter Notebook.
# HR Data Analysis using Python

This project analyzes a large-scale HR dataset (2 million employee records) of a multinational corporation to derive actionable workforce insights.

## 🔍 Objectives
- Clean and preprocess HR data for analysis
- Analyze salary structure, attrition, performance, and workforce distribution
- Identify trends to support HR decision-making
- Visualize key metrics for business interpretation

## 🛠 Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📊 Key Analysis Areas
- Data Cleaning & Validation
- Tenure and Experience Consistency Checks
- Salary Benchmarking & Outlier Detection
- Department-wise Attrition & Performance Analysis
- Workforce Distribution by Location & Work Mode

## 📈 Visualizations
- Department-wise employee count
- Salary distribution histogram
- Experience vs Salary trend
- Performance comparison across departments

## 💡 Business Outcomes
- Identified high-attrition departments
- Highlighted pay equity trends
- Provided HR recommendations for retention, hiring, and performance improvement

## 📁 Files
- Jupyter Notebook (.ipynb) with step-by-step analysis
- Visualizations generated using Matplotlib
